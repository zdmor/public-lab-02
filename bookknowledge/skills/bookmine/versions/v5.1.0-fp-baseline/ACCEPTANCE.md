## A. 第一性原理验收目标

我们的目标不是产出更多文本，而是令使用者在下一次任务中得到**比不使用此 Skill 更准确、可追溯、适当拒绝错误信息**的回答。方法有效性的证据必须来自客观回读与对照试验，而不是任务完成次数、文件数量、质量标签或者模型自评分。

拆分成三个互不替代的维度：

- **内容保真性 F**：每个关键论断来自正确版本、可定位；作者原话、归纳、拆解者假设和外部资料不混淆。
- **方法可用性 U**：可以回答具体问题、调用正确知识，并在原文不存在时合理拒绝；与旧方法相比有量化改进。
- **领域效果 E**：对 AXI 策略或工程方案有无真正增量效果，由独立研究评估，不能由 F、U 直接推出。

SPEC_LOCK 仅说明文本固定；F、U、E 都没有因为版本提交而自动得到 PASS。

## B. 固定测试样本与防过拟合

选取三个已有合法源文件、版次与抽取位置可确认的独立作品：
1. Type A：交易或系统化投资的实操书；
2. Type C：论证与世界观为主体的理论书；
3. Type D：有表格、图、公式和边界条件的技术/工程工具书。

另设一组故障注入：缺失源、错误版次、错误页码、无出处“1.5 倍”等派生阈值、重复 T ID 以及同名不同作品。测试书的具体名称和固定来源 SHA 在开始实验前写入 EVAL_MANIFEST（不得跑完再挑书）。不得向公开仓库上传完整原书或受版权保护的图表。

**对照组**：N1 原 BookMine v5.0；新 BookMine v5.1-FP；开源 book-to-skill 原版（只在可运行的范围比较），每组相同材料、任务、模型、预算、抽取能力和冻结输入。记录执行环境、代码版本和成本。随机种子预登记；人工盲评者不知输出来自哪组。

每本最少检验 10 个主要论断，尽量覆盖章节、正反例和数字性主张；独立的问题集合包含 3 个常规查询、2 个要求引用的决策查询和至少 2 个陷阱/拒绝查询。样本不足必须标 NOT_EVALUABLE，不用缩小口径凑 PASS。

## C. 必须实现的机器检查

| 检查 ID | 检查对象 | 成功条件 | 失败处理 |
|---|---|---|---|
| QC-01 | Work/Edition/Source | 唯一键清楚、输入文件 SHA、版次可追踪 | 隔离记录；不把同名当同版 |
| QC-02 | 文本提取 | 章节、图表、公式漏失清单可回读；原文遗漏显式记录 | 降级为 PARTIAL_EXTRACT |
| QC-03 | 核心断言出处 | 关键断言有正确可定位 source_locator，版次匹配 | 标 TRACE_FAILED，禁止“来源已证实” |
| QC-04 | 作者/研究者区分 | SOURCE_NOT_QUANTIFIED 不得被派生阈值覆盖；原文无数值不伪造 | 关键误归属为硬失败 |
| QC-05 | T 注册与引用 | ID 单义、双向映射；冲突 legacy ID 留歧义且阻断 canonical 自动绑定 | 标 AMBIGUOUS，不擅自改旧记录 |
| QC-06 | 状态语义 | 全部状态有对应证据；无自动从文件齐全推导 FULL_READ | 无证据退回 UNKNOWN / NOT_TESTED |
| QC-07 | 依赖/冲突 | depends_on、conflicts_with 要么可解析，要么 NOT_EVALUATED | 绝不可伪称无冲突 |
| QC-08 | 输出版权/权限 | 公开产物不含全文、长段替代摘录、图片和本地敏感路径 | 阻止公开提交 |
| QC-09 | 生产隔离 | 不修改旧 N1 Skill/T 注册、AXI 业务规则与定时器 | 任意未授权写入视为失败 |

## D. 预先登记的性能判据（候选门槛）

以下是**验收目标，不是已测成绩**。实现前必须用同一测试集正式跑旧版基线，避免事后修改判据。

- **零容忍**：关键数值的伪造作者归属 = 0；引用错误作品/版次而声称 VERIFIED = 0；未经授权写入正式系统 = 0；对冲突旧 ID 静默自动归并 = 0。
- **关键出处可回指率**：≥ 95%，且所有不能定位的关键断言必须明确标 UNLOCATABLE 而非凑数。
- **标注与状态正确性**：≥ 95% 的样本判定经盲评或原文回读一致；故障注入的强制拒绝场景 100% 正确拒绝或降级。
- **效用**：同题盲评质量不得劣于 v5.0，且至少在一个预注册目标维度有可重复改善；报告效果大小、例数和不确定性，不用“差一点就通过”的主观裁决。
- **成本**：记录 tokens、处理时间、抽取成本、二次查询上下文成本；成本上升须换取明确质量收益，不以“自动生成 Skill”本身作为收益。

以上阈值是第一版工程候选验收门槛；样本少的实验只能作 pilot，不宣称统计意义上的普适优越性。领域 E 另行按项目协议回测/复验，不能用上述指标代替。

## F. 分阶段验收证据包

**G0 文本锁定**：GitHub 上有版本路径、blob SHA、commit SHA；回读版本与文件内容一致。允许写 SPEC_LOCKED，只表示可重复取得该文本。

**G1 静态可执行检查**：完成上述 QC-01–QC-09 的测试规范、测试样例和运行回执。只读审计通过不等于 G2 通过。

**G2 小规模盲测**：预注册样本集、对照组输出、每条失败定位、成本和评分；报告所有失败和样本限制。不达阈值则保留为候选并形成修订版，不重写已经锁定的文件。

**G3 项目适配验证**：AXI 只能导入 RESEARCH_CANDIDATE，不得直接改 M0–M3、FINALIZER 的正式阈值、持仓规则、定时或审批权限。候选逻辑需要 PIT 数据、交易成本、样本外与前向对照；工程场景需要适用标准、材料/工况和重复实验。

**G4 正式接入**：另经对应 Owner 批准、固定不可变工件版本、运行测试、精确回读及回滚验证。未发生之前只可报告 NOT_APPROVED。
